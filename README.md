## About Me

I'm a developer interested in building useful applications, designing APIs, and exploring how software works under the hood.

My interests include:

- **Full-Stack Development** — Building applications from frontend to backend.
- **Backend Engineering** — REST APIs, authentication, database design, and application architecture.
- **Developer Tools** — Exploring programming languages, runtimes, and tools that improve the development experience.
- **Mobile Development** — Building applications with modern mobile technologies.
- **Performance & Security** — Understanding optimization, secure implementation, and reliable software design.
- **Exploration** — Learning new technologies through experimentation and hands-on development.

I value practical solutions, maintainable code, and understanding the fundamentals rather than relying entirely on abstractions.
